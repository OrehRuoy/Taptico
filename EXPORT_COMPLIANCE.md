# Export Compliance — Taptico

## App Information

- **App Name:** Taptico
- **Bundle ID:** com.orehruoy.taptico
- **Platform:** iOS

## Encryption Declaration

Taptico uses only encryption exempt under U.S. export regulations:

- HTTPS/TLS provided by the operating system (standard network stack)
- No proprietary or non-exempt encryption algorithms implemented by the app

## App Store Connect Setting

```
ITSAppUsesNonExemptEncryption = false
```

This key is included in the iOS export preset additional plist content.

## Compliance Statement

The developer confirms that Taptico does not implement non-exempt encryption beyond what is exempt under Category 5 Part 2 notes to the Export Administration Regulations (EAR), and qualifies for self-classification/report exemption.
