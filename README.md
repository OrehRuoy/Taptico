# Taptico

**Haptic Fidget & Focus Tool** — a Godot 4.6.3 iOS app with CoreHaptics, accelerometer-driven physics, and StoreKit lifetime unlock.

## Requirements

- Godot **4.6.3-stable**
- Xcode **16+** (iOS builds)
- Apple Developer account ($99/year)
- macOS for iOS export and native plugin compilation

## Privacy page (App Store Connect)

Hosted file: [`privacy.html`](privacy.html)  
Intended public URL: `https://orehruoy.github.io/Taptico/privacy.html`

In the GitHub repo: **Settings → Pages → Deploy from a branch → `taptico-app` / root** (this repo has no `main` branch yet). Contact: hallanhype@gmail.com

## Quick Start (Editor)

1. Open this folder in Godot 4.6.3.
2. Run the project (`F5`). Combination Lock and Toggle Switches are free.
3. Use the **bottom tabs** or the **< >** buttons to switch modules. Click and drag the lock dial. Tap switches. Unlock Forever shows **$4.99** in the editor.

## Modules

| Module | Free | Description |
| --- | --- | --- |
| Combination Lock | Yes | Angular dial with selection haptics |
| Toggle Switches | Yes | Spring-loaded heavy snap switches |
| Bearing Chamber | Lifetime | 5 metallic balls driven by tilt |
| Theremin Pad | Lifetime | Ambient noise with touch filter |
| Key Matrix | Lifetime | Linear / Tactile / Clicky double-pulse keys |

## In-App Purchase (Guideline 3.1.1)

- **Product ID:** `com.orehruoy.taptico.lifetime` (non-consumable)
- **US list price:** $4.99 in App Store Connect — the in-app UI never hardcodes this
- Paywall always includes **Restore Purchases**
- Purchase / restore failures (cancel, offline, timeout) clear the busy state and show a message; Close stays enabled
- Create the IAP in App Store Connect before device testing
- Local Xcode testing: `StoreKit/Taptico.storekit`

## iOS audio

Theremin brown noise uses `AVAudioSessionCategoryPlayback` (`audio/general/ios/session_category = Playback`). It continues if the hardware mute switch is on, like an instrument rather than a game.

## iOS Export

1. Build native plugins (macOS):
   ```bash
   chmod +x native/build_plugins.sh
   ./native/build_plugins.sh
   ```
2. Enable **Haptics** and **StoreKit** plugins in the iOS export preset.
3. App Store icon: `assets/icons/icon_1024.png` (also `ios/AppIcon.appiconset`)
4. Launch storyboard: generated by Godot from the iOS preset, overlaid with [`ios/LaunchScreen.storyboard`](ios/LaunchScreen.storyboard) in CI
5. Export Xcode project to `build/ios/Taptico.xcodeproj`

## CI/CD

[`.github/workflows/ios-build.yml`](.github/workflows/ios-build.yml) imports the Distribution certificate and `.mobileprovision` **before** `xcodebuild`, writes [`ios/ExportOptions.plist`](ios/ExportOptions.plist) with team ID + profile UUID, cleans derived data, archives, and uploads to TestFlight.

Local Mac: `bundle exec fastlane ios beta` (uses the same ExportOptions + clean derived data).

## App Store Connect Setup

1. Create app **Taptico** with bundle ID `com.orehruoy.taptico`.
2. Primary category: **Utilities**. Secondary: **Productivity**.
3. Add non-consumable IAP `com.orehruoy.taptico.lifetime` at $4.99 (US).
4. Host [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md) at a public HTTPS URL.
5. Export compliance: **No** non-exempt encryption (`ITSAppUsesNonExemptEncryption = false`).

## Privacy

100% on-device. No analytics, no accounts, no third-party SDKs. [`ios/PrivacyInfo.xcprivacy`](ios/PrivacyInfo.xcprivacy) declares UserDefaults (`CA92.1`), system boot time (`35F9.1`), file timestamp, and disk space. See [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md).

## Desk Stand Mode

When Lifetime Unlock is active, charging + landscape + still device triggers ambient desk-stand UI (keep screen on, minimal chrome). There is no public MagSafe-only API; charging detection uses `UIDevice.batteryState`.
